## Athlete-facing text

A message is athlete-facing when it is a `text` block on an `assistant` record that is not a
sidechain (`isSidechain` false). Tool calls, tool results and subagent records are not. The
message numbers below count those blocks from 1 in file order; the `uuid` is the record's.

## Leaks, by hand

Terms the athlete should never have read: a verb name, a flag code, a Draft or its fields, a
store id (`pv-n`, `b-<date>`, session ids), a file path, a commit hash, "the engine", "the
store", "dry run", "acknowledgement" used as a system term.
